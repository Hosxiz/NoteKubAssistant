# StudyAssistant

StudyAssistant คือเว็บแอปพลิเคชันสำหรับช่วยสรุปเนื้อหาจากโน้ตหรือข้อความที่ผู้ใช้ป้อน โดยพัฒนาด้วย Flask เหมาะสำหรับนักเรียนและนักศึกษาที่ต้องการย่อเนื้อหาเพื่อทบทวนบทเรียนอย่างรวดเร็ว

## ความสามารถโดยสังเขป

- รับข้อความหรือโน้ตที่ผู้ใช้ต้องการสรุป
- ประมวลผลและแสดงผลสรุปในรูปแบบที่อ่านง่าย
- ช่วยลดเวลาในการทบทวนเนื้อหาจำนวนมาก
- ใช้งานผ่านเว็บเบราว์เซอร์ภายในเครื่อง

## วิธีใช้งาน

1. เปิดโปรเจกต์ในเครื่องและติดตั้งแพ็กเกจที่ระบุไว้ในไฟล์ `requirements.txt` หากมี
2. เริ่มต้นเซิร์ฟเวอร์ Flask ตามคำสั่งที่กำหนดไว้ในโปรเจกต์ เช่น

   ```bash
   python app.py
   ```

3. เปิดเว็บเบราว์เซอร์ไปยัง URL ที่ Flask แสดงในหน้าจอ (โดยทั่วไปคือ `http://127.0.0.1:5000`)
4. ป้อนหรือวางข้อความที่ต้องการสรุปลงในช่องข้อความ
5. กดปุ่มสรุปผล แล้วอ่านผลลัพธ์ที่แสดงบนหน้าเว็บ

## เหมาะสำหรับ

- สรุปโน้ตจากการเรียน
- เตรียมเนื้อหาสำหรับการสอบ
- ย่อบทความหรือข้อความยาว ๆ
- ทบทวนประเด็นสำคัญของเอกสาร

> หมายเหตุ: คุณภาพของผลสรุปขึ้นอยู่กับเนื้อหาที่ป้อนและการตั้งค่าของระบบ หากต้องการใช้งานฟังก์ชันเพิ่มเติม โปรดดูเอกสารภายในโฟลเดอร์ `study_ui/docs` ของโปรเจกต์
