# StudyAssistant

StudyAssistant คือเว็บแอปพลิเคชันสำหรับช่วยสรุปเนื้อหาจากโน้ตหรือข้อความที่ผู้ใช้ป้อน โดยพัฒนาด้วย Flask เหมาะสำหรับนักเรียนและนักศึกษาที่ต้องการย่อเนื้อหาเพื่อทบทวนบทเรียนอย่างรวดเร็ว

## ความสามารถโดยสังเขป

- รับข้อความหรือโน้ตที่ผู้ใช้ต้องการสรุป
- ประมวลผลและแสดงผลสรุปในรูปแบบที่อ่านง่าย
- ช่วยลดเวลาในการทบทวนเนื้อหาจำนวนมาก
- ใช้งานผ่านเว็บเบราว์เซอร์ภายในเครื่อง

## วิธีใช้งาน

 คลิกลิ้ง studyassistant-3h61.onrender.com

## เหมาะสำหรับ

- สรุปโน้ตจากการเรียน
- เตรียมเนื้อหาสำหรับการสอบ
- ย่อบทความหรือข้อความยาว ๆ
- ทบทวนประเด็นสำคัญของเอกสาร
